コスめぐり

コス名ではじめる

本名も素顔も預かりません。アカウントはコス名だけで成立します。

メールアドレスは Firebase Authentication 側にのみ保管され、コスめぐりのデータには保存しません。

1エージェントに相談する

イベント・日付・作品/キャラ・出発駅・荷物が揃うと、一日ぶんを組み立てます。

2当日の組み立て

ウィッグ×衣装×メイクの完成予想図を生成します（GMI Cloud）。製作・購入の前に方向性を確かめるためのものです。

移動中とメイク中は画面を見られません。工程と動線を母語で読み上げます（GMI Cloud）。ボイスクローンは使いません。

3当日モード（自律進行）

遅延の再計算と撤収アラートは Cloud Scheduler から定期起動し、結果はお知らせ欄に届きます。ここでは時刻を進めて再現します。

4顔を解析する

肌タイプと顔属性の数値だけを保存し、画像は解析後すぐに破棄します。

5合わせ（幹事業務）

到着監視とリスケの起案までが自律。枠の確定は主催者の承認を通します。

6監査ログ

画像の破棄・位置共有の有効期間・リスケ承認は、すべて証跡が残ります。

お知らせ

顔画像は解析後に破棄。位置共有はイベント当日限定で、終了24時間後に自動削除されます。
